# Изменения (незакоммичено)

## 0.2.2

- Клик по серверу в сайдбаре подключает/отключает его
  (`context.client.api.mcp.connect` / `disconnect`, как встроенный `/mcps`).
  На время вызова строка показывает `Connecting`; ошибки — тостом.

## 0.2.1

- Добавлен корневой сворачиваемый узел `MCP (N)`: общее число MCP; внутри —
  классы `Класс (Nk)` с числом серверов в классе и вложенными серверами.
- Счётчики у заголовков теперь — количество MCP (без `активно/всего`).

## 0.2.0

- Смена подхода: **класс не зашивается в имя сервера**. Список MCP
  группируется по классам в TUI (сайдбар сессии), а имена серверов и
  инструментов остаются исходными.
- Плагин переписан как TUI-плагин (`plugin/tui.tsx`): рисует секцию MCP в
  `sidebar.content` так, что каждый класс — сворачиваемый заголовок (как
  встроенный «MCP»), а серверы вложены под него со статусом.
- Неклассифицированные серверы идут в класс `Other` и рисуются **в конце**.
- Класс по умолчанию и состав классов настраиваются (`defaultClass`,
  `classes`).
- Встроенная плоская секция отключается директивой в `cli.json`:
  `"plugins": ["-opencode.sidebar.mcp"]`.
- Серверная часть (`plugin/index.js`) теперь пустая заглушка; логика
  группировки вынесена в чистый `plugin/classes.js` с юнит-тестом.

## 0.1.0

- Первая версия: серверный плагин, деливший MCP через переименование в
  `<Класс>/<имя>`. Отброшено — префикс в имени портил инструменты и не давал
  настоящей вложенности.
